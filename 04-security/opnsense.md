# VM100 — OPNsense

## Role

LAB firewall and gateway.

---

# Interfaces

| Interface | Purpose |
|---|---|
| WAN | ISP connection |
| LAN | LAB network |

---

# Features

- VLAN routing,
- DHCP,
- firewall rules,
- DNS forwarding,
- NAT.

---

# Security Design

- LAB isolated from DOM network,
- outbound filtering,
- firewall logging enabled.
