# Restore Validation

## VM131 — FILE-01-RESTORE-TEST

Purpose:

- validate VM backup,
- validate restore procedures,
- ensure backup integrity.

---

# Validation Process

1. Create backup.
2. Restore as VM131.
3. Isolate network.
4. Validate files and shares.
5. Document results.

---

# Key Principle

A backup is not considered valid until restore testing has been completed.
